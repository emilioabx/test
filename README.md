# Générateur de Gradient HSL

Un générateur de gradient CSS simple et minimaliste avec contrôle HSL.

## Fonctionnalités

- Couleurs "From" et "To" en format HSL (Hue, Saturation, Lightness)
- Contrôle de l'angle du gradient (0-360°)
- Aperçu en temps réel dans un rectangle orientation paysage
- Interface compacte et minimaliste
- Copie du code CSS en un clic
- Design sombre et moderne

## Utilisation

Ouvrez simplement `index.html` dans votre navigateur web.

### Contrôles

- **From**: Couleur de départ du gradient
  - H (Hue): Teinte (0-360)
  - S (Saturation): Saturation (0-100%)
  - L (Lightness): Luminosité (0-100%)

- **To**: Couleur d'arrivée du gradient
  - H (Hue): Teinte (0-360)
  - S (Saturation): Saturation (0-100%)
  - L (Lightness): Luminosité (0-100%)

- **Angle**: Direction du gradient (0-360°)

Le code CSS généré peut être copié via le bouton "Copier le CSS".

## Technologies

- HTML5
- CSS3
- JavaScript vanilla (pas de dépendances)
